# ESXi-knowledge-base
28-page Word training manual designed to be both a repeatable hands-on course and a long-term ESXi knowledge base


I created a **28-page Word training manual** designed to be both a repeatable hands-on course and a long-term ESXi knowledge base.

It includes **15 hands-on labs plus a capstone**, covering ESXi fundamentals, the Host Client, users and SSH, virtual networking, VMFS/storage, ISO management, VM creation, VMware Tools, snapshots and recovery, monitoring/logs, maintenance mode, CLI administration, host configuration backups, and safe patch/upgrade dry-run practice. I also included command cheat sheets, troubleshooting decision trees, baseline/change/VM worksheets, validation checklists, administrator challenges, and a six-week suggested mastery schedule.

I intentionally **did not put your ESXi passwords into the document**. The manual is written so you can safely share it as training material.

I think the most valuable way to use this is to actually work through it against the **second ESXi server you're planning to build**. That gives us freedom to intentionally break things, troubleshoot them, practice recovery, and even test an ESXi upgrade without risking your working `192.168.1.139` host. As we discover things during your labs, we can continue expanding this manual into your own **TovarTech ESXi Administrator Knowledge Base**.
